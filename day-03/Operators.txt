4. Relational Operators: we have and, or, not
========================
and: All the conditions should be true
or: any one condition should true
not: if the condition true the output should be false

a=10
b=20
a%2==0  and b%2==0
True
a%3==0 and b%3==0
False
a%2==0 and b%3==0

# or condtion
a%2==0 or a%3==0
True
#not condition
not a%2==0
False


5. Membership Operators:  we have in,not in
=========================
Membership operators check if a value exists within a sequence (like a list, string, or tuple).

6. Identity operators: we have is, is not 
======================
Identity operators check whether two variables refer to the same object in memory.

7:Bitwise Operators: we have & | ^ ~ << >>
left shift add zeros
right shift remove zeros
