PYTHON – INPUT AND SPLIT METHOD

1. INPUT FUNCTION
=================
input() is used to take input from the user.
Syntax:
variable = input("message")
Example:
name = input("Enter a name: ")
Input:
lakshmi

name
Output:
'lakshmi'

#By default, input() always takes the value as a STRING.


2. CONVERT STRING INTO INTEGER

If we want to convert string into integer, use int().
Syntax:
variable = int(input())
Example:
marks = int(input("Enter marks: "))
Input:
100
Output:
100
"100"  → String
100    → Integer

3. CONVERT STRING INTO FLOAT
If we want decimal values, use float().
Syntax:
variable = float(input())
Example:
cgpa = float(input("Enter CGPA: "))
Input:
8.4
Output:
8.4
If we enter:
9

Output:
9.0


5. SPLIT() METHOD
split() method is used to separate a string into multiple parts.
Syntax:
string.split()
Example:
names = "vishnu lakshmi siva"
names.split()
Output:
['vishnu', 'lakshmi', 'siva']

#By default, split() separates the string using SPACE.

6. SPLIT USING COMMA
=====================
We can give a separator inside split().
Example:
names = "vishnu, lakshmi, siva"
names.split(',')
Output:
['vishnu', ' lakshmi', ' siva']

Here comma (,) is used as the separator.

7. SPLIT USING HYPHEN (-)
Example:
courses = "python-html-sql-dsa"
courses.split('-')

Output:
['python', 'html', 'sql', 'dsa']

split('-') separates the values using -.

9. CONVERT INPUT INTO TUPLE

If we use tuple(input()), it separates each character.

Example:
names = tuple(input("Enter names: "))
Input:
lakshmi vishnu
Output:
('l', 'a', 'k', 's', 'h', 'm', 'i', ' ', 'v', 'i', 's', 'h', 'n', 'u')

To get words, use split():

names = tuple(input("Enter names: ").split())

Input:
lakshmi vishnu siva baji

Output:
('lakshmi', 'vishnu', 'siva', 'baji')


10. MULTIPLE INPUT VALUES

Example:
marks = input().split()

Input:
12 34 68 5 75 4

Output:
['12', '34', '68', '5', '75', '4']



11. MAP() FUNCTION

map() is used to apply a function to every value.

Example:
marks = input().split()

marks = list(map(int, marks))

Input:
12 34 68 5

Output:
[12, 34, 68, 5]

Here int converts every string into an integer.
